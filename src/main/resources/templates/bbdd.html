7. ANALYZE para cerrar la carga

No se han analizado las tablas
  • aviso

Hasta que no se analizan, PostgreSQL no sabe cuántas filas tiene cada tabla ni cómo se reparten sus valores, y los planes de EXPLAIN se basarían en estimaciones por defecto. Se ejecuta ANALYZE sobre cada tabla en el orden de Kahn.

8. pg_dump y registro

No se ha exportado la base de datos
  • aviso

El propio servidor de PostgreSQL genera el respaldo con COPY (SELECT 1) TO PROGRAM 'pg_dump … -F c': formato custom (binario y comprimido) con las tablas, los datos, las secuencias, las restricciones y los índices, que se restaura con pg_restore. Después la base de datos se registra como BBDD objetivo en el repositorio de la aplicación, para poder analizar consultas sobre ella.
